# Third-party code

Talko 2 Drums is free software under the GNU General Public License, version 3
only (`LICENSE`). It includes the following code from Felucca by Leo Kuroshita
(@kurogedelic), Hügelton Instruments, unmodified, in `third_party/felucca/`.

| File | What it is | Licence | Source |
|---|---|---|---|
| `drum_voice.c` | Felucca's DRUM voices and its eight model kits | GPL-3.0-only | [hugelton/Felucca](https://github.com/hugelton/Felucca) `firmware/src/drum_voice.c` |
| `dsp.c` | Shared fixed-point DSP helpers | MIT | [hugelton/Felucca-Engines](https://github.com/hugelton/Felucca-Engines) `src/dsp.c` |
| `felucca_engine.h` | The engine interface `dsp.c` expects | MIT | Felucca-Engines `src/felucca_engine.h` |
| `gen_engine_tables.py` | Generator of the sine, pitch, filter and soft-clip tables | MIT | Felucca-Engines `tools/gen_engine_tables.py` |
| `fe_tables.h` | Generated by `python3 gen_engine_tables.py fe_tables.h` (44,100 Hz) | MIT | — |

The MIT licence text is in `third_party/felucca/LICENSE-MIT-Felucca-Engines.txt`.
Felucca's GPL-3.0 text is the same as this project's `LICENSE`. Commits and
SHA-256 hashes are in [third_party/felucca/UPSTREAM.md](third_party/felucca/UPSTREAM.md).

The reverb, ring modulator, phaser and tape effects in `src/effects.cpp` and
the panel, startup and PWM code follow Talko Monk (GPL-3.0-only).

## Names

"Felucca" and "Hügelton Instruments" are names of Hügelton Instruments. Talko 2
Drums is an independent project: it is not affiliated with, endorsed by or
supported by Hügelton Instruments, Felucca or Hortator. The kit names (STD, 80,
10, 66, 55, 77, DEEP, TIGHT, PERC, H+CYM) are Felucca's.

## Sharing the firmware

A UF2 built from this folder is firmware derived from Felucca. Whoever receives
it must also be offered this complete source, including `third_party/`, under
GPL-3.0.
